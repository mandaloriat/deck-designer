# Contributing

    pnpm install
    pnpm build
    pnpm test

`pnpm test` needs a Chromium binary for the renderer suite; without one those
tests skip and the rest still run. `deck doctor` reports what was found.

## Working on it

- `packages/core` must stay free of browser and network dependencies. If a change
  needs a browser, it belongs in `packages/render`.
- Anything a user can get wrong should produce a `Diagnostic` with a stable code,
  not a thrown string. Codes are namespaced (`data/`, `asset/`, `render/`) and
  are part of the public surface.
- New CLI output goes through `Reporter`, so `--json` and `--quiet` keep working.
- The example deck in `examples/starter-deck` is generated by `deck init`. Edit
  `packages/cli/src/scaffold/files.ts` and regenerate with
  `node packages/cli/dist/bin.js init examples/starter-deck --force`.
